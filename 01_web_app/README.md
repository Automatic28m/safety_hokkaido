# 01 Web App

Next.js interface for Safety Hokkaido.

```powershell
Copy-Item .env.local.example .env.local
npm install
npm run dev
```

The development server opens on `http://localhost:3000`. Set `BACKEND_API_URL` in `.env.local` when the FastAPI service is not running at `http://127.0.0.1:8000`.
